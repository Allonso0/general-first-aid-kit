**Название проекта:** Клиент-серверное мобильное приложение “Общая аптечка”

**Цель проекта:** разработка мобильного приложения для совместного управления запасами лекарственных
средств в рамках коллективных аптечек.

**Краткое описание задач:**
1. Реализация функционала учета лекарств с поддержкой сканирования штрихкодов
2. Создание системы совместного доступа к аптечкам
3. Разработка системы уведомлений о сроке годности и остатках лекарств
4. Создание удобного интерфейса для пользователей без технической подготовки

**Стек технологий**
- UI: Jetpack Compose
- Архитектура: Clean Architecture + MVVM
- DI: Hilt
- Backend: Firebase (Auth, Firestore)
- Асинхронные операции: Kotlin Coroutines & Flow
- Загрузка изображений: Coil
- Сканирование штрих-кода: CameraX и Ml-Kit от Google
- Сторонние API: 
  - EANDB-API для получения информации о лекарстве по штрихкоду
  - GigaChatAPI парсинга и структуризации полученной информации

**Как запустить проект у себя**
1. Клонируйте репозиторий
2. Подключите свой проект к Firebase и добавьте файл google-services.json в папку app/
3. Включите Authentication через email и password в консоли Firebase
4. Соберите проект в Android Studio и запустите приложение на эмуляторе
